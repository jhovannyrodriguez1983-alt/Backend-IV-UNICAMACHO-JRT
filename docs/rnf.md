# Requerimientos no funcionales

## RNF-01 - Disponibilidad
El sistema deberá estar disponible durante el horario de operación definido para los usuarios.

## RNF-02 - Seguridad
El sistema deberá proteger la información de los usuarios y evitar el acceso no autorizado.

## RNF-03 - Rendimiento
El sistema deberá responder a las solicitudes de los usuarios en un tiempo adecuado bajo condiciones normales de uso.
